# Holberton School - Machine Learning

## Supervised Learning

### Decision Tree

This project implements a basic **Decision Tree** using Python and NumPy.

#### Classes

- **Node**: Represents an internal node of the tree.
- **Leaf**: Represents a leaf node containing a value.
- **Decision_Tree**: Handles tree creation, depth calculation, and predictions.

#### Features

- Recursive calculation of tree depth
- Binary tree structure: nodes either have two children or are leaves
- Supports maximum depth and minimum population constraints
- Easily extendable for more tasks, including Random Forest and Isolation Forest
